## 3. 今天踩过的坑（下次别再踩）

1. **PowerShell 5.1 + 大小写重复环境变量**：在被托管的 shell 里 `Start-Process` 直接抛 `Item has already been added`。任何脚本起进程前先收敛重复键（`duplicate-env-keys-selftest.ps1` 可验证）。
2. **`.ps1` 里的非 ASCII 必须带 UTF-8 BOM**：`cyberboss-watchdog.ps1`（含 `♻️`）曾因丢 BOM 被按 GBK 解析，守护静默死了 4 天。
3. **数进程别用 `-like '*xxx.js*'`**：排查命令自己的命令行里就含这个字符串，会把自己数进去（今天据此误判出"每分钟重复实例"，实际只有一个 bot）。用带路径的锚 + 排除 `runner.js`。
4. **不要用 `schtasks.exe` 起可见程序**：本机把控制台交给 Windows Terminal，会闪窗；用 `Schedule.Service` COM。
5. **canary 不能是收件箱窗口**（`config.js:360` 硬拒，bot 直接起不来）；canary 需要"能自动产生回复"的目标，历史上只有 Azzy 自己满足。
6. **心跳"永久红/永久 deferred"会掩盖真故障**：今天两条红线（模型金丝雀、无通知义务的验证）都属于"等的东西不存在"，处理原则是让状态如实反映现实，而不是留着红。
